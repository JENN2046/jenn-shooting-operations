## 实质裁定

| 问题 | 结论 |
|---|---|
| 固定捕获状态能否作为限定用途的参照 | 技术上自洽。可重建状态不等于全部应有历史提交；方法将重建、历史缺口、当前绑定分开处理。 |
| 是否充分披露标准变化及代价 | 是。明确取消本案历史窗口缺口的单独否决效力，同时披露可能存在未捕获提交、不能恢复这些数据；未包装成原证据已经充分。 |
| 当前生产义务是否被削弱 | 没有。完整摘要绑定、可信来源、完整 Schema10→11 比较、持续保护和新鲜性仍强制；四时间字段例外不扩散。 |
| 是否存在不可由本案版本化例外处理的冲突 | 未发现。变化仅涉及未来治理参照资格，不能证明原 G2 切换满足 prestate/writer 要求，也不能追认旧切换。 |
| 固定材料绑定是否准确 | 两份 R1 合同、原重建回执、独立终审及窗口裁定的摘要和大小重新计算一致；档案、成员、镜像、工具绑定与此前核验材料一致。 |
