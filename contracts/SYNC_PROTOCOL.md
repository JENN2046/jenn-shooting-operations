# Sync Protocol v1

## 事实源划分

云端共享事实：

- `products`
- `tasks`
- `sessions`
- `revision`
- `updatedAt`

本机 UI 偏好：

- `view`
- `monthAnchor`

本机偏好不覆盖云端，也不影响其他查看者。

## 角色

| 角色 | 查看排班 | 提交需求 | 修改排班 | 管理备份与成员 |
|---|---:|---:|---:|---:|
| viewer | 是 | 否 | 否 | 否 |
| submitter | 是 | 是 | 否 | 否 |
| scheduler | 是 | 是 | 是 | 否 |
| administrator | 是 | 是 | 是 | 是 |

生产环境默认不提供匿名写入。鉴权未配置时，所有写接口失败关闭。

## 拉取

1. VCP 适配器读取云端快照。
2. 若云端 `revision` 大于本地已知版本，合并共享字段。
3. 本机 `view` 与 `monthAnchor` 保持不变。
4. 新需求进入待排任务池，不自动生成场次。

## 排班写入

1. VCP 生成唯一 `operationId`。
2. 请求携带本地已知 `revision`。
3. 服务端在同一事务中检查版本并写入。
4. 成功后返回新 `revision` 和快照摘要。
5. 版本不一致返回 `409 REVISION_CONFLICT`，不得覆盖；客户端先刷新再由 Jenn 决定。

## 需求提报

- 每次提报由服务端生成任务 ID。
- `operationId` 相同的重试只创建一次。
- 提交只增加待排任务，不允许修改场次。
- 图片和附件先绑定同一个 `operationId`，需求保存成功后再归属到生成的任务。
- 单次最多 10 个文件、总计 40 MB；可执行文件和文件签名不匹配的伪装格式被拒绝。
- 必填字段缺失或类型不符时返回稳定错误，不保存半条记录。

## 离线

- 工作台继续显示最后一次已确认快照。
- 本地修改写入待同步队列，不伪装成云端已保存。
- 恢复网络后按 `operationId` 顺序重放。
- 遇到版本冲突立即停止后续重放并提示人工处理。

## 审计

审计记录只保存动作类型、角色、实体 ID、版本、时间和结果，不保存凭据、Token 或原始请求头。
